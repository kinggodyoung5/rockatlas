# ROCK ATLAS taxonomy v2 마이그레이션

## 안전 원칙

- 기준선은 GitHub의 `backup/pre-taxonomy-v2-20260719` 브랜치와 `pre-taxonomy-v2-20260719` 태그에 보존한다.
- 기존 `catalog.json`, `genres.json`, 공유된 `#band=` 주소는 마이그레이션이 검증될 때까지 삭제하거나 덮어쓰지 않는다.
- `primaryGenre`와 `genreIds`는 역할이 같은 새 필드로 전면 개명하지 않는다.
- 표시용 `subgenres` 문자열은 보존하고 안정적인 필터용 `subgenreIds`를 병행 추가한다.
- 분위기 점수는 사실값이 아니라 운영자가 수정할 수 있는 편집 분류다. 의미 있는 항목만 저장하고 누락은 0으로 취급한다.

## 구 장르의 기본 이동 방향

| 기존 장르 | 기본 대상 | 밴드별 재검토가 필요한 경우 |
|---|---|---|
| `classic-rock` | `classic-roots-rock` | 팝·소프트, 하드·글램, 프로그레시브 성향 |
| `hard-rock` | `hard-glam-rock` | 스토너, 팝·소프트, 전통 메탈 성향 |
| `progressive-art` | `progressive-art-psychedelic` | 얼터너티브를 대표 정체성으로 보는 밴드 |
| `punk-rock` | `punk-emo` | 포스트펑크·뉴웨이브 성향 |
| `alternative-indie` | 밴드별 판정 | 얼터너티브·그런지, 팝·소프트, 모던 메탈, 포스트펑크로 분산 |
| `britpop-indie` | 밴드별 판정 | 인디·브릿팝·가라지, 슈게이즈·드림팝·포스트록, 포스트펑크로 분산 |
| `heavy-metal` | 밴드별 판정 | 전통·파워·스래시, 프로그레시브, 모던 메탈로 분산 |
| `extreme-metal` | `extreme-metal` | 포크·심포닉 또는 프로그레시브가 대표 정체성인 경우 |

장르 단위 일괄 치환은 하지 않는다. 46개 밴드 각각에 대해 대표작 시기와 현재 `subgenres`, `tags`, `eraTags`를 검토해 새 대표 장르를 하나만 지정한다.

## 단계별 전환

1. `taxonomy.v2.json` 자체 검증
2. 기존 카탈로그를 읽는 dry-run 마이그레이션 보고서 생성
3. 밴드별 대표 장르와 세부 장르 ID 검수
4. 분위기 점수 초안을 별도 파일에서 검수
5. Studio가 새 필드를 읽고 수정할 수 있게 확장
6. 새 UI가 구·신 데이터 어댑터를 모두 처리하는지 확인
7. 전체 검사가 통과할 때만 `catalog.json`과 공개 UI를 원자적으로 전환

제안서의 기본 세부 장르 외에도 현재 카탈로그에서 이미 사용 중인 재즈 록, 록 오페라, 네오 프로그, 슬러지 메탈, 포스트 브릿팝, 노이에 도이체 헤르테 등을 보존용 확장 항목으로 포함한다.

## 이번 단계에서 의도적으로 하지 않는 일

- 장르당 최소 밴드 수 강제
- 인기도 점수 생성
- 활동 상태 추정
- YouTube 모달 복원
- 기존 데이터나 URL 삭제
- 자동 추천을 검수된 영향 관계로 저장
