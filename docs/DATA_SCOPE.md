# ROCK ATLAS 데이터 범위 정책

## 지역 범위

초기 카탈로그는 북미·유럽·오세아니아의 서양 록 계보를 중심으로 구성합니다. 특정 언어권을 영어권으로 제한하지 않으며, 독일·핀란드처럼 비영어권에서 국제적 록 계보에 영향을 준 밴드도 포함합니다. 한국 밴드는 현재 제품 범위에서 제외합니다.

국가 값은 현재 국적이나 멤버 국적이 아니라 밴드가 결성된 장소를 기준으로 저장합니다. `origin`에는 도시와 국가 또는 구성국을 함께 표시하고, `countryCode`에는 ISO 3166-1 alpha-2 국가 코드를 사용합니다.

## 장르 범위

홈 탐색은 9개 대분류를 유지합니다. 한 밴드는 목록 배치용 `primaryGenre` 하나와 교차 탐색용 `genreIds` 여러 개를 가지며, 실제 음악적 세부 구분은 `subgenres`에 별도로 저장합니다.

활동 시기에 따라 장르가 달라진 경우 `eraTags`에 시대, 당시 대분류, 세부 장르, 변화 설명을 기록합니다. 시대 필터는 결성 연도만 보지 않고 이 편집 태그를 사용하므로, 오래 활동하며 음악이 변한 밴드는 여러 시대에 나타날 수 있습니다.

## 확장 우선순위

다음 데이터 확장에서는 현재 비어 있는 재즈 록·서던 록·포스트 록·슈게이즈의 대표 밴드를 먼저 추가합니다. 대분류를 새로 만들기보다 기존 클래식 록, 프로그레시브·아트 록, 얼터너티브·인디 록 안에 세부 장르로 연결합니다.

새 밴드는 외부 식별자, 본문 사실, 이미지 권리, 공식 영상, 관계 근거의 다섯 검수 기준을 모두 거쳐야 `reviewed` 상태가 됩니다. 자동 검색 결과만으로 승인하지 않습니다.
