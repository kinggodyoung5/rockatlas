# 새 밴드 검수함 사용법

이 기능은 개발 지식이 없는 운영자가 여러 밴드를 빠르게 추가하되, 기존 데이터를 덮어쓰거나 미검수 정보가 공개되는 일을 막기 위한 입고 절차입니다.

## 가장 쉬운 사용 순서

1. 프로젝트 폴더의 `운영자페이지-열기.bat`를 더블클릭합니다.
2. **밴드명으로 검증 자료 만들기**에 이름만 입력하고 **자동 조사**를 누릅니다. 동명이인이면 Wikidata·MusicBrainz 후보를 한 번씩 고릅니다.
3. **검증 자료를 Gemini에 보낼 문장 복사**를 눌러 Gemini 채팅에 붙여넣습니다. Studio가 확인한 결성지·정규 앨범·멤버 근거가 함께 전달됩니다.
4. Studio의 **Gemini Gem 지침 v7 복사** 내용을 Gem 지침에 한 번만 저장합니다. v7은 외부 ID·이미지·영상 URL·밴드 관계를 만들지 않고, 소개와 장르·분위기 초안에 집중하며 정식 세부 장르 ID 목록을 사용합니다.
5. Gemini 답변 전체를 검수함에 붙여넣고 **자동 정리·검사**를 누릅니다.
6. 초록색 **초안 추가 가능** 항목을 선택한 뒤 **선택한 밴드 초안 추가**를 누릅니다.
7. 왼쪽 밴드 목록에서 추가된 내용을 열어 소개·분류·분위기·출처를 확인합니다.
8. Studio 맨 위의 **전체 저장**을 누릅니다.

기존 밴드는 데이터 관리의 **기존 카탈로그 사실 검수**에서 선택 검사 또는 전체 검사를 실행합니다. 결과는 자동 저장되며, 외부 자료와 다른 값만 모아서 보여줍니다. 외부 값을 적용하는 버튼은 자동 확정이 아니라 편집 화면에 넣어 주는 기능이며, 운영자가 확인한 뒤 전체 저장해야 실제 데이터에 반영됩니다.

검수함에 붙여넣은 내용은 저장하기 전까지 현재 브라우저에 임시 보관됩니다. 브라우저를 닫았다가 다시 열어도 남지만, 다른 PC나 다른 브라우저로 자동 이동하지는 않습니다.

## 색상의 의미

- 초록색: 필수 형식과 중복 검사를 통과했습니다. 비공개 초안으로 추가할 수 있습니다.
- 노란 경고: 추가는 가능하지만 소개 길이, 분위기, 외부 식별자 등을 나중에 보완하는 편이 좋습니다.
- 빨간 오류: 이름·국가 코드·중복처럼 저장 전에 반드시 고쳐야 할 문제입니다. JSON을 수정하거나 Gemini에 오류 문구를 보여주고 다시 요청합니다.

## 자동으로 보호되는 항목

- 기존 밴드 목록을 덮어쓰지 않고 뒤에만 추가합니다.
- 같은 ID, 같은 이름, 같은 Wikidata·MusicBrainz 식별자의 재등록을 막습니다.
- 새 밴드, 대표곡, 관계, 장르 분류는 모두 `초안` 상태로 고정합니다.
- 외부 이미지의 권리는 언제나 `검토 필요` 상태로 되돌립니다.
- 존재하지 않는 관계 대상과 자기 자신을 향한 관계는 검수함에서 제외합니다.
- `groovy-funky → groovy-danceable`처럼 뜻이 분명히 같은 과거 ID·자주 쓰는 표현은 정식 분위기 ID로 바꾸고 변환 내역을 보여줍니다. 의미가 여러 갈래인 표현은 임의로 맞추지 않고 경고로 남깁니다.
- 세부 장르는 ID·한글명·영문명뿐 아니라 띄어쓰기, `락/록`, 한두 글자 오타와 자주 쓰는 음역 차이를 정식 ID로 통일합니다. 예: `사이케딜릭 락 → psychedelic-rock`, `가라지 록 → garage-rock`.
- 랩 록·파워 팝·인디 포크·포스트 메탈 등 검토된 주요 누락 장르는 정식 taxonomy에 포함합니다. 반면 `펑크 메탈`처럼 punk/funk 중 뜻이 갈리는 표현은 자동 분류하지 않고 검토 대상으로 남깁니다.
- YouTube 영상은 주소 형식과 존재 여부뿐 아니라 oEmbed의 영상 제목·채널이 입력한 밴드명·곡명과 맞는지도 확인합니다.
- 삭제·비공개·엉뚱한 영상은 직접 링크를 버리고 `밴드명 + 곡명` YouTube 검색 링크로 바꿔, 깨진 주소가 공개 화면에 남지 않게 합니다.
- 실제 파일 저장 직전에 전체 카탈로그의 중복, 끊어진 관계, 장르·세부 장르·분위기 ID를 한 번 더 검사합니다.
- 소개글에 `(1989), (1993) 등의 앨범`처럼 앨범명 없이 연도만 오면 대표곡에 적힌 앨범명·연도로 자동 보완합니다. 대표곡에도 앨범명이 없으면 추측하지 않고 공개 승인을 막습니다.
- `former` 멤버의 활동연도가 `현재`까지로 적힌 명백한 모순은 `current`로 보정하고 보정 내역을 보여줍니다.
- 오류가 발견되면 파일을 쓰기 전에 저장을 중단하므로 기존 카탈로그와 자동 백업은 그대로 유지됩니다.

## 여러 AI를 함께 쓸 때 권장 역할

- Gemini: 요청문에 맞춰 사실과 출처를 조사하고 JSON 초안을 만듭니다.
- Studio 검수함: 형식을 통일하고 명백한 누락·중복·잘못된 ID를 자동 검사합니다.
- 운영자: 최종 문체, 대표 장르 한 곳, 분위기 점수, 이미지 권리와 출처를 판단합니다.
- Codex·Claude: 대량 데이터 품질 검수, 알고리즘·UI 변경, 빌드 검사와 Git 반영을 맡깁니다.

이 분담은 효율적입니다. 다만 AI가 가져온 사실·영향 관계·분위기 점수는 자동으로 “정답”이 되지 않으므로, 공개 전 운영자 또는 별도의 검수 단계가 필요합니다.
