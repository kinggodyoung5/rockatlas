# ROCK ATLAS 디자인·운영·서버 전환 원칙

이 문서는 취미용 정적 사이트로 운영되는 현재 단계와, 나중에 서버를 붙여 공식 서비스로 확장할 때 모두 지켜야 할 기준이다. Codex와 Claude는 디자인이나 Studio 구조를 바꿀 때 이 문서를 함께 확인한다.

## 1. 변하지 않는 운영 원칙

- 개발 지식이 없는 운영자가 코드 없이 문구, 색상, 배경, 장르 카드 삽화와 강도를 조절할 수 있어야 한다.
- 디자인 설정, 밴드 데이터, 장르 분류 데이터는 서로 분리한다.
- 화면에 보이는 이름과 설명은 수정할 수 있지만 밴드·장르·분위기의 내부 ID는 기존 연결과 공유 주소를 보호하기 위해 유지한다.
- 브라우저에만 남는 임시 상태를 공개 데이터의 원본으로 사용하지 않는다.
- Studio에서 업로드한 파일은 프로젝트의 `public/uploads`에 저장하고 설정에는 상대 URL만 기록한다.
- 새 장식은 데이터 추가 작업과 무관하게 공통 설정으로 모든 기존·신규 밴드에 자동 적용되어야 한다.
- 모바일, 키보드 탐색, 충분한 글자 대비와 `prefers-reduced-motion`을 항상 보존한다.

## 2. 디자인 원칙

- 방향은 단순한 우주 배경이 아니라 **락의 우주를 기록한 항해 지도·천문 아카이브**다.
- 별, 성운, 좌표, 궤도선은 정보보다 앞서지 않도록 낮은 강도로 사용한다.
- 큰 사진을 페이지마다 중복 삽입하지 않는다. 공통 배경은 CSS, 작은 반복 무늬, 압축된 래스터 자산으로 구성한다.
- 장르 카드는 서로 붙은 표가 아니라 여백과 개별 테두리를 가진 독립된 레코드 슬리브처럼 보이게 한다. 기본 표현은 삽화 전체 위에 가독성 그라데이션과 편집 가능한 문구를 겹치는 방식이며, 별도의 동일한 베이지 설명 상자를 반복하지 않는다.
- 이미지 위 문구는 밝기가 제각각인 원본 이미지에 직접 의존하지 않는다. 문구를 카드 하단의 고정된 안전 영역에 묶고 충분히 어두운 스크림과 그림자를 적용해 일반 글자는 WCAG AA 4.5:1, 큰 글자는 3:1 이상의 대비를 확보한다.
- 장르 삽화는 인물·앨범 커버·상표를 모방하지 않는 오리지널 악기·음향 장비·추상 상징을 사용한다.
- 『은하수를 여행하는 히치하이커를 위한 안내서』의 특정 표지, 캐릭터, 로고, `DON'T PANIC` 그래픽은 직접 모방하지 않는다.
- Studio는 운영 도구이므로 공개 사이트보다 장식을 줄이고 정보 구조와 가독성을 우선한다.

## 3. 설정으로 관리할 항목

- 우주 테마 켜기/끄기와 표현 강도
- 별 밀도, 성운 강도, 움직임 강도
- 우주 보조색과 전체 배경 이미지
- 장르 카드 열 수, 카드 간격, 카드 표현 방식
- 장르별 삽화 URL, 표시 여부, 위치, 투명도와 확대율
- 히어로 이미지, 로고, 워드마크, 폰트와 기존 페이지 문구

새로운 디자인 기능을 추가할 때는 화면마다 값을 하드코딩하기보다 위 설정 구조에 편입할 수 있는지 먼저 검토한다.

## 4. 향후 서버 전환 시 지킬 경계

- 현재 JSON 파일은 수백 개 규모까지 편집 원본으로 사용할 수 있다. 규모가 커지면 동일한 필드 구조를 데이터베이스 레코드로 이전한다.
- Studio 화면은 유지하고 저장 계층만 `로컬 파일 API`에서 `관리자 서버 API`로 교체할 수 있도록 한다.
- 업로드 파일은 서버 전환 시 객체 저장소/CDN으로 이동하고, 데이터에는 이동 가능한 상대 경로나 자산 ID를 기록한다.
- 밴드별 공유·검색 주소는 장기적으로 `/bands/{id}`, 장르는 `/genres/{id}` 형태로 이전하되 기존 `#band=` 주소는 리디렉션 또는 호환 처리한다.
- 공식 운영 단계에서는 초안, 검수, 공개 상태와 버전 복구를 분리한다. 현재의 간소화된 공개 규칙은 취미용 단계의 사용자 결정으로 유지한다.
- 소개글, 이미지, 외부 링크에는 출처·권리·검수 상태를 추적할 수 있는 필드를 계속 보존한다.
- 디자인 설정에는 스키마 버전을 두고, 필드가 추가될 때 기존 설정을 기본값으로 보완하는 마이그레이션 경로를 유지한다.

## 5. 금지할 구현

- 페이지별로 서로 다른 대형 배경 이미지를 코드에 직접 박아 넣기
- 밴드·장르 이름을 화면 문구와 내부 ID에 동시에 사용하는 구조
- 장르 카드 문구를 이미지 안에 합성해 운영자가 수정할 수 없게 만들기
- 장식 때문에 본문 대비, 클릭 영역, 모바일 성능을 희생하기
- 새 설정을 추가하면서 기존 사용자 편집값을 초기화하기
- 공식 서비스 전환을 이유로 현재 정적 사이트를 성급하게 서버 구조로 전면 재작성하기
