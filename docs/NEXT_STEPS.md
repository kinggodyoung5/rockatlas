## 바로 다음 순서

1. 메인 → 장르 → 세부 장르 → 밴드 상세 이동을 데스크톱과 모바일에서 확인
2. 전체 밴드 검색·필터·정렬과 뒤로 가기 URL 복원을 확인
3. 분위기 1·2·3개 조합, 결과 없음, 초기화를 확인
4. Studio에서 장르 카드와 밴드 분위기를 수정해 로컬 저장 경로를 확인
5. 키보드 초점, 메뉴, 버튼 이름, 빈 결과 안내를 확인
6. 초기 JavaScript 약 598KB를 화면 단위 동적 로딩으로 줄일지 결정
7. 검토용 작업 브랜치를 원격에 올리고 사용자에게 결과 화면 제시
