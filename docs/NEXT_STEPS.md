# ROCK ATLAS 다음 개발 단계

이 문서는 중기 로드맵이다. 매 작업 시작 시 실제 상태와 정확한 다음 행동은 루트의 `PROJECT_STATUS.md`를 우선한다.

## 현재 완료된 기반

- 13개 상위 장르·111개 세부 장르·24개 분위기
- 133개 공개 밴드와 밴드별 정적 상세·공유 페이지
- 공개 목록의 최소 데이터 분리와 상세 진입 시 개별 데이터 로드
- 로컬 전용 Studio의 밴드 추가·검수·관계·디자인 편집
- Gemini JSON 검수함과 미등록 관계 자동 보류·후속 연결
- 관계 양방향 동기화와 낙관적 저장 충돌 방지
- 운영자 콘솔 요약과 안전한 배포 전 검사·빌드
- 밴드별 관련 방향을 자동 선별하는 히치하이킹 추천, 자동 저장 여행 경로와 공유 URL
- 더블클릭으로 작업본·Git 이력을 함께 보관하는 로컬 전체 백업

## 확정된 다음 순서

1. 운영자 실사용 확인
   - 밴드마다 선별된 최대 4개 방향의 추천 품질과 문구 확인
   - 모바일에서 후보 선택·여정 공유 확인
   - 승인 뒤 현재 작업 일괄 커밋·푸시·배포
2. 운영자 콘솔 2단계
   - 작업 순서 안내
   - 최근 검사 결과 보존
   - 로컬 전체 백업 실행 상태와 최근 백업 시각 표시
3. 추천 품질 운영 로그
   - 방향별 후보가 어색한 사례를 Studio에서 기록
   - 밴드명 예외 코딩 없이 분위기 가중치 한 곳에서 보정
4. 데이터 규모 증가 뒤 검색·장르 관리 도구 확장

## 규모가 더 커진 뒤 검토

- 밴드·장르·세부 장르·분위기 통합 검색
- 사용되지 않는 세부 장르와 분위기 매칭 실패 로그
- 장르별 추천 순서와 대표 밴드 고정
- 서버 운영 전용 인증·다중 운영자·기기 간 동기화

장르당 최소 밴드 수, 인기도 점수, 자동 활동 상태 추정, YouTube 임베드 복원은 계획에서 제외한다.
