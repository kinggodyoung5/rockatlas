## 4. 탐험지도 고도화

현재 지도는 선택한 밴드와 직접 연결된 1단계 관계를 보여 줍니다.

다음 버전:

- 관계를 양방향 검증하고 근거 출처 연결
- 관계 점수를 `음악적 유사성 / 영향 / 동시대 장면 / 멤버 교류`로 분리
- 2단계 이웃까지 펼치는 인터랙티브 그래프
- 장르·시대·국가 필터
- 이미 방문한 노드와 탐험 경로 표시
- “왜 추천되었나요?” 설명 패널

처음부터 자동 추천 모델을 쓰기보다 편집자가 검수한 관계 그래프를 충분히 만든 뒤, 태그 유사도 점수를 보조 신호로 추가하는 것이 적합합니다.

## 5. 제품 기능

- 밴드/장르별 고유 URL 라우팅
- 즐겨찾기와 개인 탐험 기록
- “이 밴드에서 시작하기” 공유 카드
- 앨범 단위 입문 가이드
- 접근성: 모달 포커스 트랩, 키보드 그래프 이동, 이미지 대체 텍스트 검수
- 한국어/영어 인터페이스 분리
- 사용자 댓글은 로그인·신고·차단·관리 정책을 정한 뒤 도입
